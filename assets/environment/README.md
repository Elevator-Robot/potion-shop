# Potion-shop environment art

The active room now uses the detailed pixel-art assets in **`pixel_shop/`**;
see [its frame and regeneration guide](pixel_shop/README.md). The older SVG
building textures below are retained as source/reference art. `window_light.png`
is still used as a translucent light overlay.

Original SVG assets authored for this project, with no external asset dependencies.
Editable source artwork is imported by Godot as ordinary textures. The floor and
light overlay also have baked PNGs: Godot's SVG importer does not render their
pattern/mask features reliably. The scene uses those PNGs.

- `oak_floor.svg`: 640×420 floor, staggered boards, grain, knots, nails and edge shading.
- `stone_blocks.svg`: repeating 128×64 masonry tile for the raised back wall and cutaway sides.
- `stained_glass.svg`: 88×100 arched stone window, leaded colored glass and potion motif.
- `window_light.svg`: translucent colored light cast across the floor; decorative, no collision.

The environment scene uses world-pixel dimensions matching the existing shop.
Walls and furniture retain their existing collision geometry in `client/main.tscn`.
The tall back wall is drawn outside the playable floor, so decoration does not
take away walking space. Source SVGs are the editable assets; `.godot/` imports
are generated by Godot.

Rebuild the two baked textures after editing their SVG sources (ImageMagick):

```sh
magick -background none assets/environment/oak_floor.svg assets/environment/oak_floor.png
magick -background none assets/environment/window_light.svg assets/environment/window_light.png
```
