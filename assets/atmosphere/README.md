# Concept-led atmosphere

Generated by `tools/draw_concept_pass.py`. Original SVG sources accompany newly
drawn floor, rugs, decorated angled shelves, mushrooms, windows and thought art.
The supplied tree1/tree6 cutouts are resized and animated with canopy sway/glow;
provenance and source hashes are in `trees/sources.json`. Original concept files
are never overwritten. Three tree variants and four mushroom variants each have
four frames. Trees use 128×160 cells; mushrooms 32×40; shelves 80×128.

Terrain and floor are separate. Rear scenery sits behind actors; foreground
trees share world Y-sorting and fade where they obscure a player. Tree roots
have feathered alpha to blend into terrain. Visual references are the user's
concept folder recorded in the root agent guidance and art-direction document.
