# Concept-led atmosphere

Generated by `tools/draw_concept_pass.py`. Original SVG sources accompany newly
drawn floor, rugs, decorated angled shelves, mushrooms, windows and thought art.
Trees and terrain are original pixel drawings from `tools/draw_pixel_woods.py`.
The prior resized tree cutouts have been replaced. No concept-image pixels are
sampled: references guide mood only. Three trees (lantern elder, hanging willow,
fungus-covered spirit tree) have four frames with authored twig, foliage and
light changes. PNGs are written on the integer grid without antialiasing; SVG
pixel runs and Python drawing sources are preserved. Trees use 128×160 cells;
mushrooms 32×40; shelves 80×128. See `trees/sources.json` for provenance.

Terrain and floor are separate. Rear scenery sits behind actors; foreground
trees share world Y-sorting and fade where they obscure a player. Tree roots
meet root-and-leaf ground clusters with crisp pixel edges. Visual references are the user's
concept folder recorded in the root agent guidance and art-direction document.
