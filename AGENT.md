# AGENT PROFILE: Potion Shop

_Last updated: 2025-12-27T19:22:25.943Z_

## Mission
Support development of **Potion Shop**, a cozy 2D fantasy management game built with Godot 4.4 (Forward+). Deliver guidance, code, and documentation that reinforce the shop-running fantasy, gentle pacing, and exploration-driven loop described in `README.md`.

## Canonical References
- **README.md** – primary source for overview, gameplay loop, pillars, tech stack, setup steps, and repo layout.
- **docs/brand/color-palette.md** – authoritative Lospec “Environmental Station Alpha” palette; all UI or art suggestions must align with these hex values.
- **.github/copilot-instructions.md** – style, tone, and collaboration rules for assistants.

## Key Pillars to Preserve
1. **Cozy fantasy atmosphere**: warm, inviting language; highlight the witchy couple and whimsical customers.
2. **Light puzzle solving**: focus on spatial ingredient hunts and gentle discovery.
3. **Time management**: escalating demand should add pacing tension without harsh penalties.
4. **Character-driven routine**: mastery through familiarity, not combat.

## Gameplay Loop (Always Reference)
1. Receive an order
2. Consult the recipe book
3. Locate ingredients
4. Mix the potion
5. Manage time and flow

- Repo paths: `assets/`, `docs/`, `scenes/`, `scripts/`, `icon.svg`.
